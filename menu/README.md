# เมนูอาหาร ร้านบางเวลา — A3

เมนู 5 หน้า ขนาด A3 แนวตั้ง (297 × 420 มม.) พื้นหลังดำ ตัวหนังสือขาว ตัดด้วยเส้นทอง

| ไฟล์ | รายละเอียด |
| --- | --- |
| `bangwela-menu-print.pdf` | **ไฟล์ส่งโรงพิมพ์** — ตัดตก 3 มม. + เส้นตัด (หน้ากระดาษ 317 × 440 มม.) |
| `bangwela-menu.pdf` | A3 พอดีขอบ (297 × 420 มม.) สำหรับดูเอง / พิมพ์เองที่ร้าน |
| `bangwela-menu-print-cmyk.pdf` | เวอร์ชัน CMYK ใช้เมื่อโรงพิมพ์ขอมาเท่านั้น (ดูหมายเหตุท้ายไฟล์) |
| `bangwela-menu.html` | ไฟล์ที่ใช้สร้าง PDF เปิดดูในเบราว์เซอร์ได้ |
| `build_menu.py` | สคริปต์สร้างเมนู แก้ชื่ออาหาร/ราคาที่นี่ |
| `art/*.svg` | ภาพอาหารลายเส้น 5 ชิ้น (ใช้เมื่อยังไม่มีรูปถ่าย) |
| `photos/` | วางรูปถ่ายอาหารที่นี่ แล้วเมนูจะสลับไปใช้รูปจริงอัตโนมัติ |
| `DESIGN-PHILOSOPHY.md` | แนวทางงานออกแบบที่ใช้คุมทั้งเล่ม |
| `fonts/` | ฟอนต์ Kanit (ไทย) และ Cormorant Garamond (อังกฤษ) — SIL Open Font License |

## แก้ไขแล้วสร้างใหม่

แก้ชื่ออาหารหรือราคาได้ที่ลิสต์ `SNACKS`, `FRIED`, `YUM`, `SOUP`, `CURRY`,
`STEAMED`, `STIRFRY`, `RICE`, `GRILLED`, `STEAK` ในไฟล์ `build_menu.py` แล้วรัน

```bash
pip install playwright
python3 build_menu.py --pdf                    # A3 พอดีขอบ
python3 build_menu.py --pdf --bleed            # เวอร์ชันโรงพิมพ์ ตัดตก + เส้นตัด
python3 build_menu.py --pdf --bleed --cmyk     # + แปลง CMYK (ต้องมี ghostscript)
```

## ใส่รูปถ่ายจริง

วางไฟล์รูปในโฟลเดอร์ `photos/` ตามชื่อนี้ (`.jpg` `.jpeg` `.png` `.webp` ได้หมด)
แล้วรัน `python3 build_menu.py --pdf` ใหม่ — หน้าไหนมีรูป ระบบจะใช้รูปแทนภาพลายเส้นเอง
หน้าไหนยังไม่มี ก็ใช้ลายเส้นต่อไป ผสมกันได้

| ไฟล์ | หน้า | เมนูที่ใช้เป็นภาพ |
| --- | --- | --- |
| `01-fried` | 1 | เอ็นไก่ทอด |
| `02-somtam` | 2 | ส้มตำไทย |
| `03-tomyum` | 3 | ต้มยำกุ้งแม่น้ำ |
| `04-steamed-fish` | 4 | ปลากะพงนึ่งมะนาว |
| `05-grilled` | 5 | คอหมูย่าง |

รูปจะถูกลดความอิ่มสีเล็กน้อยและไล่ขอบให้จางหายไปกับพื้นดำ ไม่เห็นเป็นกรอบสี่เหลี่ยม
พร้อมป้ายกำกับ `Pl. 01` และชื่อเมนูใต้ภาพ

**รูปชุดแรกอยู่ในคลัง Canva ของคุณแล้ว** ชื่อ `bangwela-01-fried` ถึง
`bangwela-05-grilled` (2048 × 1536 px) ดาวน์โหลดจาก Canva แล้วเปลี่ยนชื่อ
ตามตารางข้างบน วางใน `photos/` ได้เลย

ถ้าอยากใช้ภาพลายเส้นแบบอื่น แก้ไฟล์ใน `art/` แล้วแก้ค่า `art` ของแต่ละหน้าใน `PAGES`

## หมายเหตุ

- ราคาแสดงเป็นตัวเลขล้วน ไม่มี `.-` ต่อท้าย (ระบุไว้ที่ท้ายหน้าว่า "ราคาเป็นเงินบาท")
- คำที่ปรับตัวสะกดจากต้นฉบับ: สเก็ดระเบิด → **สะเก็ดระเบิด**,
  คั้วพริกเกลือ → **คั่วพริกเกลือ**, ข้าวกระเพรา → **ข้าวกะเพรา**,
  กระหล่ำปีผัดน้ำปลา → **กะหล่ำปลีผัดน้ำปลา**, ปลากระพง → **ปลากะพง**,
  ผงกระหรี่ → **ผงกะหรี่**, นึ่งซีอิ๋ว → **นึ่งซีอิ๊ว**
  (ถ้าต้องการใช้ตัวสะกดเดิม แก้กลับได้ใน `build_menu.py`)

## สั่งพิมพ์

**ส่งโรงพิมพ์**: ใช้ `bangwela-menu-print.pdf` — หน้ากระดาษ 317 × 440 มม.
งานจริงตัดที่ 297 × 420 มม. มีพื้นดำเลยเส้นตัดออกไป 3 มม. รอบด้าน และมีเส้นตัด
(crop marks) ที่มุมทั้งสี่ ฟอนต์ฝังมาในไฟล์ครบ ไม่ต้องส่งฟอนต์ตามไปด้วย

**พิมพ์เองที่ร้าน**: ใช้ `bangwela-menu.pdf` เลือก **Actual size / 100%
(ไม่ย่อไม่ขยาย)** และเปิด "พิมพ์ภาพพื้นหลัง"

### เรื่องสี

ไฟล์หลักเป็น RGB ซึ่งเป็นสิ่งที่โรงพิมพ์ส่วนใหญ่อยากได้ เพราะเขาจะแปลงเป็น CMYK
เองด้วยโปรไฟล์สีของเครื่องเขา **ส่ง RGB ไปก่อน** ถ้าเขาขอ CMYK มาค่อยส่ง
`bangwela-menu-print-cmyk.pdf` (แปลงด้วยโปรไฟล์กลางของ ghostscript
สีดำออกมาเป็น C72 M67 Y67 K88 หมึกรวม 295% ซึ่งอยู่ในเกณฑ์ปกติของกระดาษเคลือบ)

พื้นดำ A3 เต็มหน้าแบบนี้ ถ้าพิมพ์ดิจิทัลควรใช้กระดาษเคลือบด้าน แล้วขอเคลือบ
ด้าน (matte lamination) ทับ จะช่วยทั้งเรื่องรอยนิ้วมือและทำให้ดำลึกขึ้น
